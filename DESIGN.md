# Визуальная система СТЭК

Приложение для преподавателя у реального стола. Главная задача — быстро открыть занятие и объяснить решение.

Палитра: графит #171d1c, панели #202725, сукно #214e3d, светлый текст #f2f1e9, латунь #d6bc82, вторичный текст #aab4ad. Шрифт Manrope с кириллицей поставляется локально. Заголовки уверенные, без рекламной интонации. Числа табличные.

Композиция: слева постоянная узкая навигация; сверху текущий контекст и псевдоним. В основном поле приветствие, широкое приглашение к первому/следующему уроку с учебным столом, три разных по содержанию курса, компактный вход в практику. На мобильном навигация снизу.

    [ Навигация ][ Контекст                       Псевдоним ]
    [          ][ Заголовок                                  ]
    [          ][ Продолжить урок        Учебный стол         ]
    [          ][ START          CORE           PRO          ]
    [          ][ Практика                       Локальность ]

Выравнивание слева. Центрирование только внутри стола и отчёта. Сетка и линии разделяют действия, а не служат декором. Никаких фотографий казино, неона, анимации выигрыша. Карты — функциональный графический материал, не фоновая иллюстрация. Золото выделяет действие, зелёный связывает учебный стол и начало курса. Скругления различаются по роли: карта 5 px, кнопка 8 px, крупная панель 16 px.

Проверка направления: тёмная палитра задана брифом. Чтобы интерфейс не стал типовым набором статистических карточек, убраны фиктивные показатели, рекламные слоганы и декоративные графики; акцент поставлен на реальном следующем уроке, бумажных картах и последовательности обучения.
