СТЭК ACADEMY — МАСТЕР-ПРОМПТ ДЛЯ СОЗДАНИЯ ЛЁГКОГО УЧЕБНОГО ПРИЛОЖЕНИЯ
Версия 3.0 • 60 минут на занятие • без личных кабинетов

РОЛЬ
Ты опытный full-stack разработчик, UX-дизайнер и методист по турнирному Texas Hold'em. Создай законченное, быстрое, адаптивное веб-приложение (PWA) для очной школы спортивного покера «СТЭК ACADEMY». Реализуй код, а не только макеты. Не добавляй денежные ставки, платежи, депозиты или азартные онлайн-игры. Приложение — учебный симулятор с виртуальными фишками без денежной стоимости.

ОСНОВНОЙ ПРИНЦИП
Максимально простое приложение, которое преподаватель запускает на ноутбуке, планшете или телефоне во время 60-минутного урока. НИКАКИХ личных кабинетов, регистрации, логина, паролей, ролей, админ-панели, облачной БД, обязательного сервера, платёжных интеграций и сбора персональных данных. Не добавляй их «на будущее». Один пользователь на одном устройстве. Данные уроков встроены в приложение, прогресс хранится локально на устройстве (localStorage или IndexedDB). Работает офлайн после первой загрузки. Сброс прогресса и экспорт/импорт JSON по желанию.

КУРСЫ И МАТЕРИАЛЫ
Используй три приложенных PDF как первоисточники структуры и терминов:
1. START: 8 уроков по 60 минут — правила, комбинации, позиции, префлоп, постфлоп, математика, турниры и локальные форматы.
2. CORE: 12 уроков по 60 минут — диапазоны, комбинаторика, 3-беты, EV, c-bet, SPR, короткие стеки, адаптация.
3. PRO: 10 уроков по 60 минут — GTO, эксплойт, ICM при релевантной структуре наград, MDF, овербеты, мультивей, анализ раздач.
Не подменяй PDF выдуманными главами. Перенеси все уроки в редактируемые локальные JSON/TS-модули, сохрани формулировки и явно помечай примеры как учебные. Если из PDF недостаточно данных для конкретного тренажёра, добавь авторский пример с проверенной математикой и меткой «дополнительное упражнение».

ЭКРАНЫ (ВСЕГО ПЯТЬ)
1. Главная: три больших курса START/CORE/PRO, краткая информация, прогресс на этом устройстве, кнопка «Продолжить».
2. Список уроков: названия, продолжительность 60 минут, изучено/не изучено, быстрый поиск по темам.
3. Урок: вкладки «Теория», «Термины», «Раздачи», «Практика», «Проверка»; прогресс и таймер 60 минут с рекомендованными этапами 5/20/15/15/5; удобное чтение с телефона.
4. Тренажёр: визуальный покерный стол на 3–6 мест, карты и фишки, выбор Fold/Check/Call/Bet/Raise/All-in; пошаговые учебные раздачи с правильными ответами, пояснениями и указанием позиции, стеков, блайндов, анте и борда. Никакого real-money функционала.
5. Отчёт: итог занятия и выбранного курса, сколько задач выполнено, сколько правильных, сложные темы, рекомендации и дата; красивый экран «Сделать скриншот». Уложи основные результаты в один экран 1080x1920 или адаптивный мобильный viewport, чтобы преподаватель мог просто сделать скриншот и отправить его в мессенджере. Кнопка «Скопировать отчёт текстом». Дополнительно можно «Скачать PNG» через html-to-image, но НЕ делать это обязательным и не запрашивать разрешений на доступ к экрану.

ПРОГРЕСС БЕЗ АККАУНТОВ
Для очного занятия преподаватель может ввести необязательный псевдоним или номер ученика («Ученик 1»). Не хранить телефон, e-mail, паспортные данные. На одном устройстве можно переключать локальные учебные профили по псевдониму, без авторизации и синхронизации. Никаких скрытых сетевых запросов с результатами. При очистке данных браузера прогресс может пропасть: честно предупреди и предложи локальный экспорт JSON. Отчёт по каждому ученику показывай отдельно, чтобы скриншоты не путались.

ОБЯЗАТЕЛЬНЫЕ ТРЕНАЖЁРЫ
- Комбинации: сравнение двух рук на пяти общих картах, кикеры и делёж банка; корректная оценка лучших пяти карт из семи.
- Порядок действий: кто ходит первым на префлопе и постфлопе для 3–6 игроков.
- Минимальный рейз: корректный размер полного рейза, отдельные случаи короткого олл-ина и повторного открытия торговли.
- Префлоп: позиция, эффективный стек, учебные диапазоны и объяснение, почему ответ зависит от условий.
- Математика: пот-оддсы, ауты, стек в BB, расчёт EV с показом формул; проверяй корректность округлений.
- Постфлоп: вэлью/блеф, структура доски, простой анализ диапазона.
- Турнир: уровни блайндов, анте, короткий стек; не выдавай упрощённые таблицы за универсально оптимальную стратегию.
- Локальный формат «2 Boards»: запрос при олл-ине инициатором олл-ина, максимум 2 использования на игрока, согласие оппонента не требуется, дважды открываются только нераскрытые улицы. Неопределённые спорные случаи (мультивей, odd chips, несколько запросов) пометь как «уточнить регламент клуба»; не выдумывай обязательные правила.

СИСТЕМА ОЦЕНКИ
Каждый урок: 3–8 контрольных вопросов, 2–5 учебных раздач и кнопка «Завершить». Показывай не только верный ответ, но и понятное объяснение. По курсу: итоговый тест, процент верных ответов, темы для повторения. Не оценивай качество решений только по выигрышу конкретной раздачи. Никаких автоматических денежных рейтингов.

ДИЗАЙН
Премиальный, спокойный стиль спортивного покера: тёмный графит, глубокий зелёный сукна, умеренный золотой акцент. Отличная читаемость кириллицы, крупные кнопки для телефона, контраст WCAG AA, плавные но необязательные анимации, поддержка prefers-reduced-motion. Без перегруженных дашбордов, рекламных блоков и «казино-эффектов». Доступность с клавиатуры. Карты должны быть однозначно различимы по мастям.

ТЕХНОЛОГИИ И АРХИТЕКТУРА
Рекомендуемый стек: React + TypeScript + Vite + Tailwind CSS; PWA через vite-plugin-pwa; локальное хранилище IndexedDB (например Dexie) или localStorage для простого MVP; Vitest для логики расчётов. Без backend и без платных API. Контент отдельно от компонентов: src/content/courses/*.ts или *.json. Алгоритмы оценки рук и расчётов — отдельные чистые функции с unit-тестами. Если используешь библиотеку оценки покерных рук, проверь лицензию и точность. Не делай сетевые зависимости критическими для работы офлайн.

ЭТАПЫ РАЗРАБОТКИ
Этап 1: готовый работающий проект, роутинг, три курса, уроки, локальный прогресс, адаптивный интерфейс.
Этап 2: тренажёры комбинаций, математики и префлопа, тесты корректности.
Этап 3: визуальный стол, особые правила, локальные профили по псевдониму.
Этап 4: экран отчёта, удобный для скриншота, текстовый экспорт, PWA, офлайн, финальное тестирование.
После каждого этапа приложение должно запускаться, без заглушек и неработающих кнопок.

КРИТЕРИИ ПРИЁМКИ
- Запуск: npm install && npm run dev; сборка npm run build; тесты npm test.
- На ширине 375 px нет горизонтального скролла и нечитаемых текстов.
- Все 30 уроков доступны и открываются, каждый рассчитан на 60 минут.
- Можно пройти вопрос, увидеть объяснение, сохранить локальный прогресс, перезагрузить страницу и продолжить.
- Можно переключить два локальных псевдонима без смешивания их результатов.
- Экран отчёта удобно фотографировать или сохранять скриншотом, без регистрации и без отправки данных в облако.
- Покерная математика и оценка комбинаций покрыты тестами, в том числе кикеры, общая лучшая рука, сплит-пот, короткий олл-ин.
- После первой загрузки приложение открывается без интернета.
- README описывает запуск, структуру контента, добавление уроков и ограничения локального хранения.

НАЧНИ С РЕАЛИЗАЦИИ
Сначала изучи приложенные PDF и кратко перечисли 30 уроков. Затем создай структуру проекта и реализуй MVP, не спрашивая о необязательных деталях. Не создавай регистрацию или личный кабинет ни при каких обстоятельствах. Сохраняй учебный характер приложения и удобство отправки отчётов обычными скриншотами.
